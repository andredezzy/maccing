# Listing copy: title, description, specifications

What to check while you write or review a listing's text. `references/listings.md` covers how to type it into the form.

The copy belongs to the user. Propose it, show it, and fill the form only with the text they approved.

## Read the limits live

| Fact | Where |
|---|---|
| Title and description limits | The counters under the name and description fields in the edit form. |
| Quality tasks ("Qualificado", "Excelente") | The product optimiser panel beside the edit form. Read its task list before and after you edit. |
| Attributes for the category | The specification section's "Complete: n / m" counter. Expand the show-more button first. |
| What gets a listing banned | Education centre article 5139, "Principais Motivos de Banimento e Suspensão de Anúncios". |

## Title

1. **Lead with the product type**, then what sets it apart, then size, model or material. Brand first only when the listing has a real brand.
2. **Front-load the first 45 characters.** Search cards cut the title at two lines. Those words are what earns the click.
3. **Write the words buyers type.** Try them in the Shopee search bar and read the autocomplete.
4. **End when the facts end.** Each word appears once. Details go in the specifications and the description. Shopee's own rule: "coloque somente o necessário no título".
5. **Plain text**: sentence or title case, digits for numbers ("12 cm"), a hyphen or comma where needed.
6. **Keep to the product.** Leave out promotion, shipping, price and condition words ("promoção", "frete grátis", "envio rápido", "novo"), superlatives ("mais vendido"), emojis, contacts and links.
7. **Other brands**: only for compatibility ("para iPhone"), at most 3. A third party's brand name can get the listing taken down. Name it to the user before you submit.

## Description

1. **First lines answer "what is it, how big".** The preview cuts the rest behind "Ver mais".
2. **Short headed blocks**: what it is, measurements, material, what comes in the box, where it fits, care or warranty if known.
3. **Every number from the user's record.** Leave a fact out rather than estimate it. A wrong feature is a violation too.
4. **Plain text and line breaks.** Bullets like "•" render. Links, handles, phone numbers and other platforms get the listing banned.
5. **Complete, not padded.** Shopee bans listings with too little description (code 605, with penalty points). Repeated keywords help no one.

## Specifications and category

- Fill every attribute the product truly has, from the user's record. Ask for anything unknown.
- Leave an attribute the product lacks empty, even though the "Complete" counter stays lower. A false attribute is "spam de características" (education centre article 2639). Categories list attributes for other products, such as a tapestry type, a plaque type or a size in mL.
- Use the deepest category that fits. "Outros" only when nothing more specific exists.

## Before you hand it back

Report the title's character count, what the first 45 characters say, the attribute counter, and any quality task the panel still lists.
